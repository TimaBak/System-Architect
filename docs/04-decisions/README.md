## Минимальная цепочка

~~~text
Проблема → контекст → измеримые свойства → варианты
   → риски → эксперимент → выбор → ADR
      → автоматические проверки → пересмотр
~~~

Сильное решение — не самое популярное, а то, что остается объяснимым после изменения людей, технологий и обстоятельств. **Точка пересмотра** должна быть частью решения.
