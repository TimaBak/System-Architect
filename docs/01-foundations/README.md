Этот раздел отвечает на четыре вопроса: **что делает архитектор**, **как ограничивать связанность**, **какие свойства система должна обеспечивать** и **как определить её логические части**.

Связь разделов: бизнес-сценарий → свойства качества → границы компонентов → оценка возможных стилей → ограничения и проверки.

**Важно:** логическая структура не равна физическому развертыванию. Шесть модулей могут быть одним процессом; один модуль не обязан быть отдельным микросервисом.
