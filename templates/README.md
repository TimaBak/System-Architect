# Шаблоны архитектурной работы

| Шаблон | Когда нужен |
|---|---|
| [ADR](ADR-template.md) | У решения есть заметная стоимость смены или последствия для команд |
| [Сценарий качества](quality-attribute-scenario.md) | Нужно перевести расплывчатое требование в проверяемое |
| [Архитектурное ревью](architecture-review.md) | Нужно оценить существующую или предлагаемую систему |
| [Реестр рисков](risk-register.md) | Нужно связать угрозы, последствия, проверки и ответственных |

**Правило:** шаблоны — инструменты диалога. Удаляйте поля, которые не помогают принимать решение, но не скрывайте существенные допущения.

См.: [ADR](../docs/04-decisions/adr.md), [риски](../docs/04-decisions/risks-and-fitness-functions.md).
